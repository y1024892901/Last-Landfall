# 《潮线之上》项目进度与待办

复核日期 2026-11-14。基线为 `main` 的 `f0768f0`（2026-11-02，统一资源命名并更新引用），使用 Unity `6000.6.6f1`。已同步远端与 Git LFS 资源。

11 月 15 日补充了界面、操作、建造、画面、声音和性能的逐项验收标准。详见[游戏优化清单](GamePolishBacklog.md)。

## 当前可以试玩的内容

| 模块 | 已接入当前版本 | 本次核对范围 |
| --- | --- | --- |
| 群岛与环境 | 主岛与东西副岛、三岛建造格网、主岛溪流与池塘、东副岛沉船、海上独立灯塔礁。运行时接入了新版地形、植被和岩石，海岸以岩岸为主。 | 主场景加载了 3 个地形碰撞面，格网为 241 × 249，包含岸边水域。当前草主要布置在林缘与溪边，开阔平地仍偏稀。 |
| 建筑与道路 | 建造目录有 25 类设施、29 个施工模块。普通设施有地基、结构、完善、完工四个阶段；道路可拖铺，按相邻格选择端头、直路、弯道、T 字或十字。救援码头沿低岩岸生成接岸台阶。 | 目录和资源通过检查，24 个非道路设施通过施工阶段专项检查；一个低岸码头点和占用拒绝通过检查。当前地图的四向道路实摆仍需复测。 |
| 科技、生产与人口 | R1–R9 主线研究、建筑解锁和效率研究已接入。淡化、捕鱼、温室等有产出，仓库与水罐影响容量；已有居民食水消耗、饥渴、健康和士气变化。 | 代码已接入部分效率与资源产出；尚未完成从零开始的经济平衡试玩。 |
| 船只与人物 | 海燕号救援艇和两名初始船员；人员可移动、沿码头登船或下船；船可按目标点航行，在码头装卸两个货舱。 | 船只专项通过空船出航限制、码头装载限制、货物守恒、船员保存恢复和开阔水域寻路检查。 |
| 灯塔 | 从废墟开始，经 8 道工序直至点亮。支持顺序施工、扣费、清理回收、施工续接和阶段跳转。 | 逐段施工、重复开工防护、中途进度恢复与信标点亮通过专项检查。 |
| 界面、天气与音频 | 动态首页、游戏内设置、天气与时钟、暂停和 1×/2×/3×、建筑检查器、任务与仓库页。已有 1 首首页音乐、4 首游戏内轮换音乐、基础天气环境声和雷声。 | 通过首页进游戏、首页与游戏内设置打开关闭的检查；截图发现天气控件遮挡木材栏。 |
| 快速存档 | F5 保存、F9 读档的单槽原型。记录库存、建筑与道路位置、已完成研究、人口、救援艇与货舱船员、灯塔阶段和当前工序进度。 | 船员货舱与灯塔分别有恢复验证；普通建筑、道路和研究队列的完整读档流程尚待验收。 |

本次在独立项目副本运行 Unity 检查。直接启动总检时，Unity Editor 的搜索索引在进入 Play Mode 时抛出异常；等索引启动完成再运行，场景总检通过。总检输出中的「五阶段灯塔」是旧描述，当前灯塔以 `LighthouseRebuildValidation` 的 8 道工序检查为准。

## 待办与优先级

| 优先级 | 待完成 | 验收结果 |
| --- | --- | --- |
| P0 | **让存档可用于持续试玩。** F9 现在同时触发读档和补满调试库存。补齐普通设施与道路施工进度、研究队列和法令状态，恢复旋转后码头的实际占地。新版读取旧资产名时需要走已有别名映射。 | 按 F9 只进入读档确认。重启后，库存、道路、不同朝向的码头、在建建筑和进行中的研究都能恢复；用命名整理前的存档复测。 |
| P0 | **修正淡水放置与拖路遇阻的判定。** 11 月 15 日在 Unity 中复现了淡水底部放置小屋，以及跨过被占用格仍继续铺路。 | 溪流和池塘不接受陆地建筑或道路。拖路让玩家明确知道阻挡点和实际会铺设的连续段。 |
| P0 | **接通第一段救援任务。** 船和码头已经能操作，打捞和遇险信号脚本仍未在默认场景启用。把出航、现场打捞或救人、靠岸交接和任务结算串起来。 | 从新开局出发，经由可到达的码头完成登船、出航、救援、返航，任务与库存或人口正确更新。 |
| P1 | **做出可平衡的生存开局。** 当前初始库存和基础发电还使用测试值 `999`。接入砍树、采石和资源消耗，让淡水、食物、供电和研究条件形成实际节奏。 | 玩家依靠有限随队物资和开局采集建起前哨，能通过研究解锁淡化、捕鱼，并稳定维持首批居民。 |
| P1 | **修正顶栏并验收不同窗口大小。** 解决天气控件与物资重叠。天气、时钟与倍速在左，科技、文化居中，四项资源与功能区在右侧。 | 物资四项可读且能展开更多，天气图标跟随切换，各按钮在常用分辨率下都能点到。 |
| P1 | **在当前三岛上复测建造与海岸。** 核对各向道路的连续拖铺和拼接、旋转后的长方形建筑占地、各方向码头、人物登船和船体离岸余量。 | 覆盖主岛和两座副岛，检查直线、转角、T 字、十字，并完成一次低岸码头建造与登船。 |
| P1 | **按最新地形复核美术。** 东岛沉船目前由新版场景选在鞍部，需和此前指定的搁浅点核对。复查溪源岩色、溪流入池、水色衔接、绿色地表草量、近景飘落物和最暗天气下的建造可读性。 | 从玩家常用视角、近景与夜间取画面对照，确认位置、材质和层次。 |
| P2 | **扩充剧情和中后期玩法。** 把开场概念图接成可玩的引导，补上总部补给、区域据点、船队调度和更多地图。将文化法令的描述接到人口或生产数值，并为长期水位变化添加玩法后果。 | 有一条可从新游戏进入并连续推进的章节流程，主要解锁由实际运行条件触发。 |
| P2 | **制作并验收独立试玩包。** 现有结果来自 Unity 编辑器，Windows 构建和长时间游玩需要单独验收。 | 从独立构建进入游戏，完成建造、变更天气与时间、出海和读档，并记录满负荷施工时的帧率与内存。 |
