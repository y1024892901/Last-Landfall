# 天气光照与建造可读性

运行时配置集中在 Assets/LastLandfall/Scripts/IslandWeatherSystem.cs。光照以能辨认地形、建筑和放置状态为最低要求，夜晚和恶劣天气通过明暗层次、冷色、雨和远景雾表现。

| 天气 | 白天直射倍率 | 环境光倍率 |
| --- | ---: | ---: |
| 晴天 | 1.00 | 1.00 |
| 阴天 | 0.70 | 1.04 |
| 雨天 | 0.78 | 1.00 |
| 大风 | 1.00 | 1.00 |
| 雷雨 | 0.60 | 0.96 |

这些倍率仍经过昼夜曲线，但所有天气共用直射光下限 0.46、环境光下限 0.78。默认主光强度为 0.9，因此水平地面的未染色直射光量最低为 0.414。主光强度按太阳实际入射角补偿，夜间角度最低 34°，避免低角度令纸面上的亮度下限失效。

环境光使用实时三色半球光，天空、水平面和地面分别设最低颜色；不会依赖原场景过暗的天空盒环境探针。低强度、无阴影的反向柔光补足山坡和建筑背面，阴影强度随昼夜与云量平滑变化。天气切换不再突然锁定阴天太阳角度。

树叶云量染色最低保持原色的 91% / 95% / 92%，避免与天气照明叠加后发黑。近景雾起点跟随相机地面焦点，远景仍保留天气雾。建造网格继续使用不受照明影响的着色器；绿色和红色建筑预览另有 0.18 倍轻微自发光。

验证使用相同岛屿 FBX、材质、URP 管线、天气脚本及建造网格的独立 Unity 预览项目，覆盖 5 种天气的白天与午夜。另检查 480 个天气/时刻组合、40 个天气切换起点，以及停用天气组件后的原始光照恢复。预览未运行完整游戏 HUD、雨粒子和建造交互，不能替代完整游戏验收。
