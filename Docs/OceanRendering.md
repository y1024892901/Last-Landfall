# 半写实风格化海水

海面采用连续的大尺度起伏、两层频谱法线细节、低对比的深浅水色和断续岩岸浪花。没有添加沙滩或修改岛屿地形。

## 运行接入

- StylizedFloodwater.shader：保留原着色器名称和 GUID，让运行时海面沿用原海岸距离场。移除 14 倍放大的网格法线和沿固定方向生成的宽亮纹；波面法线在片元阶段连续计算。
- FloodwaterAppearance.Configure：统一设置游戏与预览材质的颜色、起伏、细波纹和岩岸浪参数，避免预览默认值与游戏材质赋值不一致。
- 两张 OceanSlope 数据纹理：不同频谱、方向与相位，分别用 73 米和 109 米尺度、不同旋转和漂移采样，再加低频扭曲。细纹理不会直接绘制成规则亮条。
- 岩岸使用现有 signed coast distance field：局部相位控制浪花涌进、退下和破碎，减少连续白圈与宽青色水带。
- 雨天用实际雨量叠加随机位置与相位的细涟漪；风和雷雨加强起伏、细波纹与少量碎浪；云量压低眩光，昼夜光照同时影响水色。
- 启动时隐藏旧场景保存的 Floodwater 海面，防止它与新生成海面叠加。当前运行海面、池塘与溪流保持独立。

细节数据是线性斜率场，不是颜色图。OceanTextureImportSettings 将其设为 sRGB 关闭、Repeat、Trilinear、Mipmaps、512 分辨率，避免错误颜色解码和远景闪烁。每张不压缩 RGBA 纹理含 mipmaps 约 1.33 MiB，两张约 2.67 MiB。

## 生成与检查

运行 python Tools/Rendering/generate_ocean_slopes.py 可确定性重新生成两张纹理，依赖 NumPy 和 Pillow，不使用外部素材或运行时海洋插件。

独立 Unity 预览使用同一个海水着色器、FloodwaterAppearance、岛屿 FBX、天气脚本，以及从当前建造原型提取的原始海面网格和海岸距离场生成方法。

检查包括旧/新材质对照、5 种天气、雷雨午夜、岩岸近景、连续动画帧、着色器编译、纹理线性导入、旧海面排除及天气关闭后的材质参数恢复。它不包含完整游戏 HUD 或建造交互验收。

预览脚本和图像位于被 Git 忽略的 work/weather_lighting_audit/；海水输出在 WaterOutputs/。运行中的旧材质需要重新进入 Play，才能重新配置细节纹理和清理旧海面。
