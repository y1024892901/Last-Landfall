# Last Landfall 剧本与建筑科技等级方案

> 状态：当前讨论确认稿，后续可继续调整。本文记录剧本开局、建筑等级解锁、研究站推进和效率升级规则；尚未代表这些系统已在游戏中实现。

## 剧本开局

玩家带着两名船员、一艘快艇、通信设备、基础口粮、工具、初始木材和应急净水器出发。小队因侦测到附近船只的信号前往调查，抵达后发现目标已经成为沉船。

小队勘察岛屿和周边海域，通过通讯中心向总部回报。总部确认该岛适合建设前哨后，命令小队扎根发展。初始可建建筑为木棚、研究站、医疗帐篷、通讯中心和基础土路。玩家从一开始就可以砍树、挖石头；快艇、口粮、工具、初始木材和应急净水器属于随队装备。

研究站依据总部图纸开展研究，通讯中心负责与总部同步资料。图纸传输需要时间，研究站还要按本地水质、气候和资源条件验证方案。总部后续派直升机送来固定海水淡化设备、温室设备和种子。淡化设备先投入使用；温室设备可以先存放，等供水、供电和相应研究条件达成后再组装启用。

等待补给或设备校准期间，研究站可以开展捕鱼研究。捕鱼提供前期食物来源，口粮作为过渡；温室随后承担稳定种植和扩大食物供给的任务。

## 建筑等级与解锁内容

建筑等级 L 表示该类建筑首次开放的等级。研究站研究等级 R 按顺序推进；完成当前等级的主线课题后，才能进入下一级。进入新等级后，玩家再研究该等级内的具体建筑或技术。

| 建筑等级 | 阶段主题 | 建筑与设施 |
| --- | --- | --- |
| **0级：初始前哨** | 直接可建，建立落脚点和基础采集 | 木棚、研究站、医疗帐篷、通讯中心、基础土路。可砍树、挖石头。快艇、口粮、工具、初始木材和应急净水器为随队装备。 |
| **1级：饮水与近海资源** | 研究站建成并完成首次数据同步后开放 | 固定海水淡化装置、储水设施、漂木收集浮栅、渔船码头、基础仓库、救援码头、居民小屋。捕鱼工具可作为早期研究课题。 |
| **2级：供电与医疗** | 稳定供水后开放 | 太阳能发电站、电路、医疗站。首批设备可使用总部随设备送达的临时电源；此级开始建设本地供电。 |
| **3级：食物与加工** | 供电和基础卫生条件达标后开放 | 高科技温室、公共厨房、废料拆解工坊、锻造炉。温室设备需完成组装、校准和种植研究后才能运作。 |
| **4级：区域救援** | 温室开始产出、基地物资较稳定后开放 | 救援指挥／长距通讯站、气象与潮位浮标、船坞、救援前哨。初始通讯中心负责本地及总部联络；本级设施扩展到远距离联网和救援调度。 |
| **5级：社区与文化** | 建立区域联系并接纳其他居民后开放 | 学校、档案馆、议事厅，推动知识传承、共同记忆和聚落自治。 |

渔船码头负责持续捕鱼，救援码头负责快艇出任务。若实际玩法中两者差异不足，可以合并为多用途码头，再通过升级区分功能。

## 研究站主线推进

研究等级按顺序开放。每一级设置一个必须完成的主线课题，用于推进到下一级；该级具体建筑和科技仍需分别研究。

| 研究等级 | 主线方向 | 推进结果 |
| --- | --- | --- |
| **R0** | 初始知识与前哨建设 | 可使用随队装备并采集木材、石头。 |
| **R1** | 岛屿水文、饮水保障与漂木流向 | 开放1级建筑与近海资源研究。 |
| **R2** | 稳定供水、太阳能与基础医疗 | 开放2级建筑。 |
| **R3** | 温室、种植与食物加工 | 开放3级建筑。 |
| **R4** | 长距通信、海况观测与救援调度 | 开放4级建筑。 |
| **R5** | 教育、档案和社区治理 | 开放5级建筑。 |
| **R6–R9** | 后期效率、自动化和区域协作 | 深化各级设施，完成后期研究与效率提升。 |

## 建筑效率研究

建筑解锁等级为 L：

- 第一次效率研究在 **R = L + 2** 开放，效率提升 **10%**。
- 第二次效率研究在 **R = L + 4** 开放，再提升 **15%**。
- 每种建筑最多研究两次；两次完成后，相对基础值累计提升 **25%**，不进行复利计算。
- 对应建筑必须已经建成并运行过，研究站才能依据运行数据开展效率研究。研究完成后对所有同类型建筑生效。
- 每种建筑明确一种主要效率指标：生产设施提高产出，通讯设施提高覆盖或稳定性，医疗设施提高救治能力，仓储设施提高容量等。

| 建筑等级 L | 第一次效率研究 | 第二次效率研究 |
| --- | --- | --- |
| **0级** | R2：+10% | R4：+15% |
| **1级** | R3：+10% | R5：+15% |
| **2级** | R4：+10% | R6：+15% |
| **3级** | R5：+10% | R7：+15% |
| **4级** | R6：+10% | R8：+15% |
| **5级** | R7：+10% | R9：+15% |

## 设计原则

- 生存推进顺序为：**饮水 → 供电与医疗 → 食物生产与加工 → 区域救援 → 社区发展**。
- 捕鱼和随队口粮承担温室稳定产出前的食物过渡。
- 岛上砍树和挖石头用于初期建设；漂木收集浮栅提供后续木材来源，避免长期依赖砍伐岛上森林。
- 人口带来劳动力、专业技能和救援能力，也增加水、食物、住所和医疗需求；人口规模本身不是唯一胜利目标。
- 本方案是剧本与系统设计记录，建筑清单、研究等级、资源产出和解锁条件仍需在后续实现与平衡。
