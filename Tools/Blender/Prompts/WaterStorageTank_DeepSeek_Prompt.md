# WaterStorageTank：DeepSeek 建模代码生成要求

请先查看我附上的六视图概念图，再按下方要求生成完整 Blender Python 脚本。概念图用于确定结构与六个方向的对应关系；最终模型必须符合项目内其他建筑的低多边形游戏美术风格，不要照搬概念图的写实材质细节。

## 背景与用途

《Last Landfall》讲述一支三人小队乘快艇前往调查信号，抵达后发现目标船只已经沉没。中央随后命令小队在岛上扎根发展。初期设施包括木棚、研究站、医疗帐篷和通讯中心。研究站依据中央图纸逐步研发基础设施；固定海水淡化装置负责制水，本建筑是独立的淡水储存与分配设施，用来储存淡化后的饮用水并连接营地管线。

这是 **WaterStorageTank（淡水储水设施）**，不是海水淡化厂，也不是通用仓库。造型可采用一个木质高架平台上的两个封闭式淡水罐，带检修梯、阀门、短管汇流和清晰可读的进出水管。所有零件须有合理支撑，不能悬空。整体应像能由小队利用木材、基础工具和总部运来的工业部件搭建、维修的早期殖民地设施。

## 美术与尺寸

- 美术风格：简洁、风格化、低多边形、轮廓清楚，适合等距视角的生存建造游戏。使用明确的大形体，控制小零件数量；不要照片级写实、复杂污渍、文字标签或装饰性科幻细节。
- 配色：风化雪松木、褪色海绿色/蓝绿色金属水罐、暖灰色混凝土或石质基座，少量克制的锈橙色五金件。材质与颜色应在无贴图时也能辨认。
- Blender 单位：1 BU = 1 米。
- 目标占地：3×2 米，对应 3×2 个一米网格；管件、阀门等可略微超出主体，但总超出不超过约 0.15 米。
- 总高：不超过 2.4 米。
- 建筑中心位于世界原点；底部最低点为 Z=0；建筑正面朝 -Y。
- 按游戏资产规模搭建：避免细到远景看不见的零件，主要结构在缩略图中仍要清楚。

## 六视图基准

附图是 3 列×2 行的正交概念图，顺序固定如下：

| 位置 | 视图 | 方向 |
|---|---|---|
| 第一行左 | Front | 从 -Y 朝 +Y 看，建筑正面 |
| 第一行中 | Back | 从 +Y 朝 -Y 看，建筑背面 |
| 第一行右 | Left | 从 -X 朝 +X 看，建筑左侧 |
| 第二行左 | Right | 从 +X 朝 -X 看，建筑右侧 |
| 第二行中 | Top | 从 +Z 朝 -Z 看，俯视 |
| 第二行右 | Bottom | 从 -Z 朝 +Z 看，仰视底面 |

模型方向、梯子位置、管线走向和罐体数量应在六个方向保持一致。请把这六个视角分别渲染成独立 PNG，使用正交相机、统一目标点、统一尺度和一致的无干扰背景，便于逐张检查。另可输出一张等距预览图。

## 脚本交付要求

请输出 **一个完整、可直接运行的 Blender 5.2 `bpy` Python 脚本**，放在单一 Python 代码块中。不要只给伪代码、片段或省略号。脚本要求：

1. 只使用 Blender 自带的 `bpy`、`mathutils` 和 Python 标准库；不要联网、调用外部程序或依赖第三方 Python 包。
2. 使用 `pathlib` 处理路径。脚本从项目根目录运行时，写入下列路径；目录不存在时自动创建：
   - 源场景：`Assets/LastLandfall/Art/Source/Buildings/WaterStorageTank.blend`
   - FBX：`Assets/LastLandfall/Resources/Models/Buildings/WaterStorageTank.fbx`
   - 等距预览：`Assets/LastLandfall/Art/Previews/Buildings/WaterStorageTank.png`
   - 六视图 QA：`Assets/LastLandfall/Art/References/ScenarioBuildingViews/_renders/WaterStorageTank_Front.png`
   - `.../WaterStorageTank_Back.png`
   - `.../WaterStorageTank_Left.png`
   - `.../WaterStorageTank_Right.png`
   - `.../WaterStorageTank_Top.png`
   - `.../WaterStorageTank_Bottom.png`
3. 创建清晰的 `WaterStorageTank` 根集合，模型零件命名可读。保存 `.blend` 并导出 FBX；FBX 只包含建筑模型，不得包含相机、灯光、地面或 QA 辅助物体。
4. 生成适合游戏使用的简洁几何体和基础材质。避免意外的自相交、互相穿插、未连接管线、悬空支撑和穿过罐体的梯子。结构之间有意连接时应贴合，不要留下明显缝隙。
5. 渲染并保存六个独立正交视图。视图名称和方向必须严格符合上面的定义。渲染完成后恢复场景中的相机/渲染设置，不要因渲染某一视角覆盖错误输出文件。
6. 在脚本结束时打印实际包围盒尺寸、对象数量、输出文件路径，并做可行的网格质量诊断（例如非流形边、松散几何）；若某项诊断无法可靠自动化，请在输出中说明限制，不要伪称检查通过。
7. 脚本应可重复运行；不要删除或覆盖项目内其他建筑资产，也不要批量重建其他模型。本次只处理 `WaterStorageTank`。

请先简短说明你从六视图中读到的主要结构和方向约定，然后给出完整脚本。不要生成额外建筑，也不要把“储水设施”替换成“海水淡化装置”。
