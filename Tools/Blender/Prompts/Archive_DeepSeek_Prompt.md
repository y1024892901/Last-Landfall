# Archive_DeepSeek — Blender 5.2.2 建模脚本请求

请依据随本提示上传的 `Archive_Concept_SixViews_DeepSeek.png` 和以下约束，为《Last Landfall》制作 5 级社区档案馆 `Archive_DeepSeek` 的完整、可运行 Blender 5.2.2 Python 脚本。它属于沉船后逐步发展起来的岛屿聚落：易修、防潮、安静而有公共记忆感，不奢华。概念图仅作造型参考；尺寸、方向和输出约束以下文为准。不要声称参考图外的本地文件已上传。

## 建筑造型

- 单层小型社区档案馆，低多边形游戏美术。项目清单为 2×2 占地、最高约 2.8 米；将整体控制在 X≤4.8 m、Y≤4.8 m、Z≤2.8 m，最低 Z=0。1 BU=1 m，+Z 向上，入口朝 -Y，原点位于平面中心附近。含檐口和入口台阶也必须留在包络内。
- 建筑略微架高：暖灰色石墩、结实深色木梁和木地板底架，支点分布均衡。前入口设置短小防雨门廊/雨棚，木柱或斜撑明确落地并连接檐梁；居中双开木门，前方 2–3 级低台阶或小平台，踏步连续稳固。
- 外墙采用盐蚀暖棕色木板与深色回收木角柱、横梁，墙体封闭完整。前门旁放一块空白暖赭色社区公告板，禁止文字、图标、品牌。门上方可有克制的横向雨棚。
- 左右侧各有两扇小型高位烟蓝玻璃窗，配厚实木框与简洁可开合风暴百叶，体现对潮湿、风雨和档案日晒的防护。正面可有小窗；后墙保持朴素，仅保留少量通风口或高窗。窗框、玻璃、百叶应为分离构件，不能只画线。
- 使用紧凑、低矮的对称四坡/折坡海绿色波纹金属屋顶，四面都有足够屋檐保护木墙；屋面最多有一两块青灰维修补片，配简洁屋脊/顶盖、檐沟和一根落水管。按概念图保持小型四坡屋顶的轮廓，不做高塔或大型挑檐；不得越过总宽、总深和总高限制。
- 材质为盐蚀浅棕木、深色回收结构木、褪色海绿/青灰金属、暖灰石墩、烟蓝玻璃和暖赭公告板。低多边形块面清楚，少量小倒角；不用照片纹理、噪声污迹或文字贴图。可有一盏小型暖色入口灯。
- 六向应保持同一建筑尺寸和结构：Front(-Y) 显示公告板、双开门、雨棚、台阶与基座；Back(+Y) 显示朴素后墙、通风细节与落水管；Left(-X)/Right(+X) 各看到两扇高位防护窗；Top(+Z) 清楚看到四坡金属屋面和修补板；Bottom(-Z) 显示地板梁、石墩和门廊支撑。不得加入人物、书桌、书架室内陈设、其他建筑、地形、植被、海水、船、可读文字或品牌。
